# Measured on free Colab T4 — 2026-08-20

`unsloth/Qwen3.5-4B`, tier `T4`, fp16, 30 optimizer steps per run (2 epochs × ⌈225/16⌉),
full 50-item eval. Captured from `results/runs.csv` before the VM was recycled.

## Training — valid measurements

Training was internally consistent; the F-25 render mismatch breaks **eval**, not
training. These numbers stand.

| run | placement | r | trainable | LR | final loss | train s | peak VRAM GB |
|---|---|---|---|---|---|---|---|
| `correct` | text-linear | 16 | 32,464,896 | 1e-4 | 0.0549 | 995.5 | 12.07 |
| `attn_only` | q,v | 283 | 32,456,704 | 1e-4 | **0.0531** | 888.9 | 12.09 |
| `wrong_lr` | text-linear | 16 | 32,464,896 | 1e-5 | 0.0903 | 1021.3 | 12.08 |
| `qlora` | text-linear | 16 | 32,464,896 | 1e-4 | 0.0670 | 1084.7 | **7.15** |

* **Matched budget holds**: 32,456,704 vs 32,464,896 = 0.025% apart. `matched_rank()`
  works, and `make verify`'s <5% fairness check passes comfortably.
* **QLoRA's VRAM saving is real and large**: 7.15 vs 12.07 GB = **41% less**. That is
  the measurement NB4 Q3 asks for, and it is the honest half of the deck-§12 trade.
* **Ranked by training loss, `attn_only` WINS** (0.0531 < 0.0549). The deck calls
  attention-only placement Lỗi #1; the loss column says it is the best of the four. This
  is F-22 demonstrated: the column NB4 used to print was not merely weak evidence, it was
  *inverted* evidence.
* `wrong_lr` is the one contrast the loss column ranks correctly (0.0903, clearly worst)
  — a 10× LR error is big enough to show up even in a bad metric.

## Wall clock

Free-T4 throughput varies a lot run to run — the *same* 30-step config took 1456 s and
then 1021 s on identical code. Publish ranges.

| stage | measured | note |
|---|---|---|
| NB1 | ~25 s | CPU-only |
| NB3 (1 training run) | **15–25 min** | 888–1456 s observed; 34–48 s/step |
| NB4 (3 contrasts) | **45–60 min** | 19.8 min measured for `qlora` alone incl. load |
| NB5 (4 eval sweeps) | **21 min** | 1264 s: `correct` full 4-group + 3 contrasts target-only |
| model download | ~70 s | first run only, 9.32 GB |

fp16 sped up **generation** ~3.5× vs the emulated bf16 it replaced; it did **not** speed
up training (48.5 s/step on both). Do not describe the F-15 fix as a training speedup.
