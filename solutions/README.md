# Solutions — instructor only

Empty on purpose in the student repo.

The lab has **no single right answer** to grade against: students pick their own base
model tier, and are encouraged to swap in their own corpus. What is gradeable is the
*process* — see `rubric.md` — and `scripts/verify.py` checks the mechanical half of it
automatically (mask proof, matched parameter budget, frozen eval checksums, baseline (b)
integrity).

**For the instructor pack** (reference run on the default corpus, expected score ranges
per tier, and the worked answers to the NB4 questions), see the private instructor repo.
Do not commit reference adapters or expected numbers here — students can read this repo.
